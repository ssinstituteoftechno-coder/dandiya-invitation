# Babu, Be My Dandiya Partner? 💖

A romantic, mobile-friendly Dandiya invitation page featuring an animated compatibility meter, date-plan details, and interactive responses.

## Preview
Open `index.html` in Chrome.

## Publish as a separate GitHub Pages site
1. Create a new repository on GitHub named `dandiya-invitation`.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. After deployment, the URL will be `https://YOUR-USERNAME.github.io/dandiya-invitation/`.

This is a separate site and does not change the existing Cheeku website.
